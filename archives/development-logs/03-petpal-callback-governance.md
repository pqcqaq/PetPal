# Archive 03: Callback Governance Expansion

Covered sections: 26-48

## Scope

本卷记录 P1 阶段围绕回调治理持续展开的能力扩充，包括审计保留、失败告警、死信重放、重放日志与风险信号。

## Main Outcomes

- 对齐回调审计导出权限，避免管理页可见但导出边界不一致。
- 审计保留清理任务落地，并进一步配置化，支持不同环境按保留策略运行。
- 回调失败告警 outbox 建立，完成失败入队、定时投递、失败重试、死信终止与 Web 管理页。
- 死信批量重放能力上线，并补齐对应审计轨迹。
- 并发事务隔离与 `activeRole` 越权风险得到加固。
- replay log 逐步具备过滤查询、时间范围、分页、导出、权限拆分、统计能力和风险信号。
- outbox 与 replay log 相继补齐处理中超时、积压时长、静默风险等指标信号。
- 基于审计结果重排开发计划，把重心从回调治理继续增强切换到三端核心功能补齐。

## Resulting Baseline

- 回调链路已经从“可用”升级到“可治理、可重放、可观测”。
- 这一阶段奠定了 PetPal 后台后续值班和运营能力的核心治理框架。
